# Sistema de Conta Bancária 💳💻

Este projeto consiste em uma aplicação desenvolvida em TypeScript que simula um sistema de gerenciamento de contas bancárias. A aplicação permite representar operações comuns de um banco, aplicando conceitos de Programação Orientada a Objetos (POO) para estruturar o sistema de forma organizada e modular.

O sistema foi estruturado em diferentes camadas da aplicação, utilizando boas práticas de organização de código para facilitar manutenção e expansão das funcionalidades.

---

## 📚 Conceitos estudados

Durante o desenvolvimento deste projeto foram trabalhados os seguintes conceitos de POO:

- Classes
- Construtor
- Getters e Setters
- Classe Abstrata
- Herança
- Model
- Repository (Interface)
- Controller

---

## 🐾 Funcionalidade do projeto

A aplicação permite realizar o gerenciamento de contas bancárias, possibilitando operações básicas do sistema financeiro.
Entre as funcionalidades implementadas estão:

- Cadastro de contas
- Depósito em conta
- Saque de valores
- Consulta de informações da conta
- Transferencia entre contas

## ⚙️ Pré-requisitos

Antes de executar o projeto, é necessário ter instalado em sua máquina:

- Node.js
- npm
- TypeScript
- ts-node

### Instalar Node.js

Baixe pelo site oficial:

https://nodejs.org

Após instalar, verifique no terminal:

```bash
node -v
npm -v
```

Se aparecerem as versões instaladas, significa que o Node.js e o npm estão funcionando corretamente.

---

### Instalar o TypeScript

No terminal, execute:

```bash
npm install -g typescript
```

Depois verifique a instalação:

```bash
tsc -v
```

---

### Instalar o ts-node

O **ts-node** permite executar arquivos TypeScript diretamente no terminal sem precisar compilá-los para JavaScript.

Instale com o comando:

```bash
npm install -g ts-node
```

## 📥 Como clonar o repositório

No terminal, execute:

```bash
git clone https://github.com/BiiaBraga/Conta_bancaria.git
cd Projetinho_poo
```

---

## 📦 Instalação das dependências

Após clonar o repositório, instale as dependências listadas no arquivo `package.json`:

```bash
npm install
```

Esse comando irá instalar automaticamente as bibliotecas utilizadas no projeto, como:

- readline-sync
- @types/node
- @types/readline-sync

---

## ▶️ Como executar os arquivos

Para executar o sistema utilize o comando:

```bash
ts-node Menu.ts
```

A aplicação será executada no terminal.
